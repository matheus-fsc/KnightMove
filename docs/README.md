# docs

| caminho | conteúdo |
|---|---|
| `historia.md` | como o projeto evoluiu, passo a passo, com o raciocínio de cada virada |
| `prior-art.md` | o que já existia na literatura e o que sobrou como contribuição própria |
|  `wiki-html-legado/` | primeira wiki em HTML, mantida como registro (os stubs foram substituídos) |
| `wiki-md/` | a mesma documentação em Markdown, pronta para a wiki do GitHub |
| `notas-pesquisa/` | auditoria de citações, blueprint da formalização, plano de tightness, índices de bibliografia |
| `agent_prompts/` | prompts usados para conduzir as fases de pesquisa assistida; ficam como registro de método |
| `relatorios/` | relatórios de revisão e auditoria (`review_report`, `fix_report`, `wiki_audit`, `patch_lut_results`) |

Os artigos em LaTeX e os PDFs **não** ficam neste repositório, por decisão
explícita: são rascunhos em revisão e vivem fora da árvore de código.
