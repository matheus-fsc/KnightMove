# experiments

Organizados na ordem cronológica em que as ideias apareceram, não por tema. A
numeração é a mesma do fluxograma no README raiz.

| # | diretório | pergunta que motivou |
|---|---|---|
| 01 | `01_backtracking/` | dá para otimizar o backtracking até o 8×8 ficar viável? |
| 02 | `02_simetria_d4/` | quanto a simetria diedral D4 reduz o espaço de busca? |
| 03 | `03_amostragem/` | fixando início e fim, dá para amostrar o tabuleiro e achar padrões? |
| 04 | `04_espaco_ciclos/` | os "loops" da árvore de recursão são o espaço de ciclos GF(2)? |
| 05 | `05_solvers_xor/` | um solver SAT com cláusulas XOR resolve melhor? |
| 06 | `06_invariante_Q/` | por que o rank sempre fica 3 abaixo de beta_1? |
| 07 | `07_topologia/` | esse deficit 3 é do plano ou do cavalo? |
| 08 | `08_heuristicas/` | dá para usar a estrutura local para guiar a busca? |
| 09 | `09_cross_domain/` | o método transfere para outros problemas? |

Cada subdiretório tem README próprio com o veredito.
