# viz: geração de figuras

Scripts que produzem as figuras usadas nos relatórios e na wiki.

| arquivo | figura |
|---|---|
| `gen_gf2_cycle_figures.py` | ciclos fundamentais e XOR sobre GF(2) |
| `gen_gf2_6x6_binary_tree.py` | árvore de DFS com os ciclos fundamentais marcados |
| `gen_tour_figure.py` | um tour fechado 8×8 desenhado |
| `plot_8x8_path.py` | caminhos abertos 8×8 |
| `backtrack_tree/` | árvore de backtracking: `print_` (texto), `render_` (SVG puro), `panel_` (painel comparativo). `example/` tem saídas de exemplo. |
| `figures/` | PNGs gerados |

O frontend interativo vive em outro repositório:
[knight-tour-visualizer](https://github.com/matheus-fsc/knight-tour-visualizer).
